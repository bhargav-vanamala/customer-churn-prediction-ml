# Customer Churn Prediction using Machine Learning

## 📌 Project Overview
This project is an **end-to-end machine learning solution** to predict customer churn using **real-world telecom data**.

The goal is to identify customers who are likely to leave the service so that businesses can take **proactive retention actions** instead of reacting after churn occurs.

This project is designed as a **portfolio-ready ML project** for:
- Data Analyst
- Data Scientist
- Machine Learning Engineer roles

---

## 🎯 Business Problem
Customer churn directly impacts revenue and growth.

Key churn indicators include:
- Short tenure
- High monthly charges
- Low service engagement
- Contract type and payment behavior

Early churn prediction enables:
- Targeted retention campaigns
- Personalized offers
- Reduced customer acquisition cost

---

## 📊 Dataset (REAL DATA)
This project uses the **IBM Telco Customer Churn Dataset**, a real-world dataset published by IBM and widely used in industry and ML training.

### Key Features
- Customer demographics
- Account and contract information
- Service usage details
- Monthly and total charges
- Churn label (`Yes` / `No`)

---

## 🧠 Target Variable
- **Churn = Yes** → Customer left (1)
- **Churn = No** → Customer retained (0)

## 🤖 Machine Learning Models
Models implemented and compared:
- Logistic Regression
- Decision Tree
- Random Forest
- Gradient Boosting

---

## 📈 Model Evaluation
Evaluation metrics:
- Accuracy
- Precision
- Recall
- F1-score
- ROC–AUC

Special focus on **recall**, as missing a churned customer is costly.

---

## ⭐ Key Insights
- Month-to-month contracts show highest churn
- New customers are more likely to churn
- Higher monthly charges increase churn probability
